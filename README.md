# swift-libxray

Xray-core for Swift: the official [XTLS/libXray](https://github.com/XTLS/libXray) Apple build (`LibXray.xcframework`, cgo, static, arm64 + x86_64) as a SwiftPM binary target, plus `XrayCore`, a typed Swift wrapper over its `CGoInvoke` JSON API.

Scaffold commit; the package lands with milestone M0.
